# WCMigrate 0.6.0 / 10

迁移、配置备份和恢复时显示“请勿离开当前页面”、真实工作百分比与估算剩余时间，清点期间显示估算中。操作期间自动保持屏幕常亮，结束后恢复，无设置开关。

配置库新增“仅备份 plist 文件”：递归保留.plist（大小写不敏感）及其所在目录结构，排除其他文件、无匹配文件的空目录，不跟随符号链接。无匹配文件明确报错。配置备份仍独立可选，不作为迁移前置条件。

复制优先APFS写时复制，失败回退4MiB流复制；进度和空间检查节流，保留完整哈希校验。转换继续使用同文件系统原子交换或排他移动，不全量中转大文件。手机实际速度尚未测量。

0.6新任务持久化计划、检查点和提交日志。迁移/配置恢复可在迁移记录“检查并继续迁移”；配置备份在配置库“未完成的配置备份”继续。恢复先校验来源、目标和已完成结果，验证通过的文件跳过，未完成单文件重传。转换识别已交换状态，避免重复交换。外部修改、未知状态或权限异常会停止。旧版任务没有完整计划，无法补成可恢复任务。没有字节偏移续传、全任务回滚或任意掉电恢复保证；操作两端应用应退出。

系统选择器改由稳定UIViewController宿主直接呈现UIDocumentPicker，delegate关闭完成后导入；原SwiftUI关闭回调交接丢失曾复现，实际ZIP/plist点击测试现已通过。诊断改原生只读可选择文本与6000字符分页，复制/分享仍输出全文；尚不能据此断言iOS27内部渲染根因。

修改范围：App中的操作状态、进度、配置页、诊断页、原生文件选择器；Core中的备份/恢复/迁移引擎、持久日志、估算和诊断分页；CSupport克隆与目录检查包装；Tests、UITests、进程恢复脚本、版本/打包脚本、项目配置及文档。

验证：72项核心测试（含大文件）通过；两份2147483665/2147483679字节稀疏文件交换，完整SHA-256与inode交换通过；256MiB密集文件克隆及强制流复制通过。独立进程操作中_exit(77)，新进程恢复复制、转换、配置备份并校验内容通过。17项UI回归通过，最终进度/常亮/plist开关和历史恢复定向2项再测通过。Mac结果不代表iPhone性能，真实设备安装与运行尚未验证。
