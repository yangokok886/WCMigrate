2026-11-12。基于用户提供的三张实机截图：应用列表无图标、整行点击无响应、映射按钮过小及无明细错误弹窗。本版保留原 Bundle ID、App Group、arm64、最低 iOS17；0.4.0 / 4。

## 应用列表和图标

移除 WeChat 识别提示、筛选和识别标签；默认显示全部应用。排序按精确 com.tencent.xin、com.tencent.xin 前缀、其他 com.tencent 前缀、其他应用。暂不实现实时进程枚举。整行 Spacer + maxWidth + contentShape，选择和配置目标共用同一应用列表。

原图标使用 wq_read，内部以防链接方式逐级打开祖先目录，授权只覆盖目标安装目录时可能失败。新适配器优先用 WQ LS 记录路径，缺失时尝试 LSApplicationProxy.bundleURL；Info.plist 与 PNG 用有上限的 final-no-follow 常规文件描述符读取，必要时申请目录/文件授权。Bundle ID 匹配后读取声明尺寸/常见图标名，追加安装目录顶层最多64个以appicon/icon/iphoneicon开头的PNG候选；ImageIO缩图，最终系统图标接口回退。Assets.car仍不直接渲染，避免上游已知UIKit进程中止。

图标诊断记录实际路径来源、Info读取结果、PNG搜索、最终结果；在应用详情“图标读取诊断”查看/复制。此版本已编译，真实用户系统上的权限及图标成功率需要实机再测，不能以模拟器占位测试冒充成功。

## 映射和诊断

进入位置映射自动设置未映射项为对应路径；显式自定义映射不覆盖。目标位置是一张淡绿色可整行点击卡片，手动输入是48pt高独立次操作；仅自定义后显示“恢复对应路径”，不再并排放两个同权重小按钮。

源代码确认旧版混淆了多种失败：lstat失败和符号链接共用invalidPath，权限可能未在目录递归中逐项准备。新实现分开errno和类型错误，扫描各级前准备访问。系统应用缺少有效Group时立即给出具体签名/Group说明，保留路径检查与链接阻止，不关闭保护来硬过。

错误页可复制/分享完整诊断，含步骤、实际路径、POSIX错误码/说明、NSError域/码/userInfo、两边BundleID、路径映射、配置路径、实际Group、系统版本和WQ原始日志。设置运行日志也可复制。用户旧截图的唯一根因无法单凭泛化弹窗确定，不能断言一定是缺Group或链接；新版明细用于确认。

## 插件配置管理

插件配置页可以独立选择应用备份，不要求首页已选来源/目标。默认整个容器相对Library/Preferences，可修改配置相对目录，也可经文件App选择新的备份保存文件夹；后者记录security-scoped bookmark，重新启动恢复访问。更换保存文件夹显示新位置的记录，旧位置内容不自动搬走/删除，可切回查看。

已保存配置支持左滑ZIP分享、左滑确认删除；详情也可分享。ZIP采用上游WQArchive流式deflate，不是改后缀假ZIP。ZIP写入限制4GiB/65535条目；导入stored/deflate/ZIP64，解包上限512MiB，不支持加密。先在私有临时目录解压，拒绝越界/重复、损坏CRC/不支持压缩；不创建特殊节点，发现被跳过的链接也拒绝导入，失败不写目标应用。临时解包目录用后清理。

支持直接plist（先解析校验）及自动识别WCMigrate manifest+payload、Preferences、Library/Preferences、平铺全plist ZIP（可有单层包裹目录）。WCMigrate导出的manifest包先验证SHA256与目录结构，再进入本地配置库；普通包不声称具有可信来源签名。保留完整目录中的隐藏、嵌套、非plist配置。无法识别的ZIP明确报错，不把任意沙盒压缩包猜成配置。

本地及导入配置共用“选择应用·替换或合并配置”。替换整个配置目录并清理目标独有项；合并同名覆盖、保留独有项，不重命名；单plist只操作同名文件，替换也不会清空其他配置。目标现有配置先保护并验证；实际写入使用现有迁移引擎，每文件流式、校验、提交。无整任务回滚，不要求创建聊天副本。

设置页移除“创建可丢弃测试应用”。独立fixture生成仅保留在DEBUG且受-ui-demo参数约束的自动化测试路径，Release编译排除生成函数，没有正式入口或普通启动生成。
