# WCMigrate 页面与排版

2026-11-12。原生 SwiftUI；正式显示名称 WCMigrate，用户界面统一称“应用”。

单 NavigationStack。首页展示应用1/应用2、替换/转换/合并分段选择、模式解释、选择文件及插件配置入口，固定底部下一步。系统分组背景、绿色 accent、深浅色自适应；水平留白20pt，内容最大640pt，面板18–22pt圆角，主操作至少52pt高，小屏可滚动。

应用列表显示异步真实图标，取不到显示明确占位；不伪造微信品牌图标。不显示WeChat识别提示/筛选。精确com.tencent.xin最优先，再精确com.tencent.qy.xin、xin前缀、qy.xin前缀、其他com.tencent和其他应用。详情可查看可执行名和安装路径。自绘AppIcon为深青底、薄荷绿/白反向箭头，原生iPhone/iPad资源。

文件浏览器展示所有普通文件/目录，包括隐藏、tmp和根级文件；勾选与展开分离，44pt触控区域。映射默认对应路径。来源为静态说明，目标为76pt高可整行点击淡绿色卡片；48pt整宽次操作“手动输入路径”，仅自定义后显示44pt“恢复对应路径”。目标代表项目自身位置。确认页显示模式、双方身份、实际文件数/容量/路径、两应用退出与操作确认，底部90pt滚动空间。

替换说明1保留、2多余内容删除；合并说明同名替换、2独有保留；转换说明双方交换、缺失目标时移动。完成页要求核对两边应用。取消/失败如实提示部分完成；转换记录含pendingExchange时要求人工核对。

插件配置默认整个Library/Preferences，可更改应用内配置相对目录，保存位置固定本App沙盒。独立选择应用备份，plist/ZIP导入，本地配置左滑ZIP分享/确认删除，可选择目标应用替换/合并。不显示配置备份保存路径或更换保存位置入口。诊断页展示具体错误、路径、errno、Group和可复制日志。无全聊天备份按钮，迁移不自动备份配置，配置操作独立手动。执行/删除/扫描统一居中alert，不用顶部popover式confirmationDialog。-ui-demo仅创建并选择可丢弃测试应用，不自动执行；正式启动不种演示数据，Release排除生成函数。

SF Symbols用于功能和缺失图标占位。玻璃仅方向按钮，保留iOS26 availability和Reduce Transparency回退。系统字号、明确VoiceOver标签与测试identifier。小屏深色与普通屏浅色的4项流程测试分别通过；未完成全部辅助功能/大字号/iPad实机回归。

运行日志用分层操作卡片、日期/标题/摘要、搜索分类、独立详情及固定复制分享栏；原始诊断默认折叠。设置支持范围iOS26–27.3（27.3适配待真机验证），商店图标回退开关明确BundleID查询和商店图像区别。

## 操作与诊断

进度界面统一显示请勿离开、百分比、估算剩余时间；扫描未知总量时不伪造百分比。诊断原生只读文本分页显示，复制/分享始终使用全文。配置过滤开关为仅备份plist；常亮自动处理，无用户开关。

设置在开源分区上方独立显示版本号、作者Xuegao、TG频道、开源地址四行，外链使用系统Link打开。版本由Bundle读取，避免文案与构建信息不一致。
