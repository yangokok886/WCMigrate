# WCMigrate 0.3 用户需求实现

2026-11-12。软件正式名称 WCMigrate，版本0.3.0 / 3，原工程技术标识保留以免破坏签名与数据目录。

## 名称与图标

用户可见“实例”全部改为“应用”。自绘深青色底、薄荷绿/白色反向箭头 AppIcon，原生 asset catalog 含iPhone/iPad各尺寸与1024无透明图。生成源为 Scripts/generate-icon.swift 和 .sh，非下载第三方品牌图标。

## 应用识别

安装路径由 wq_bundle_path_for_id 返回。经wq_grant/wq_read读安装Info.plist并匹配Bundle ID后，记录CFBundleExecutable、版本、昵称。以WeChat可执行文件名识别微信候选，未运行也可识别；不承诺系统实时进程枚举。识别到时默认候选列表，可显示全部；无法识别时显示全部。所有列表com.tencent前缀优先，之后按WeChat确认和自然名称排序。名称/ID猜测不构成识别证据。

图标适配自上游WQUI.m：安装目录主图标PNG优先，2MB plist/8MB单图读取上限，ImageIO缩至180px，系统接口回退并过滤占位，异步读取缓存。避免部分系统有已知崩溃的Assets.car渲染。只接入读取，不加载外国应用代码。不伪造图标读取成功。真实授权/第三方图标待设备验证。

## 三种操作（“文件”包括文件夹）

替换：1所选内容覆盖2目标位置，2所选范围内的多余内容清除，1保留。
转换：每组路径1/2互换；目标原不存在则1排他移动到2，1该位置变为不存在。使用同文件系统原子rename交换，不拷贝整份聊天到第三个位置。不能交换时停止，不自动复制降级。
合并：1覆盖2，同名直接替换，2独有内容保留，1保留；同名类型冲突整体替换，无重命名。它是文件系统合并，不是数据库记录合并。

所有可读沙盒普通文件/目录（含隐藏、根级单文件）可选，链接/特殊文件阻止。源/目标映射支持不同行为位置及不存在的目标路径；“对应路径”显式设置相同相对路径，目标不是套层父目录。父子/重复映射、跨沙盒边界、链接越界拒绝。

## 空间和失败

仍只保存两边完整Library/Preferences，无聊天预备份。替换/合并流式单文件临时写、SHA256验证后覆盖。类型冲突若要文件替代目录，在临时文件验证后才删除冲突目录，因此该步骤非整体原子，无回滚。
转换保留inode/内容并验证两端树身份；每组原子而非多组事务。每组前记录pendingExchange，完成后记录exchanged；掉电若发生在内核操作和日志提交之间，该组状态需人工核对，不可自动重试。中断记录部分完成。没做自动续传、全任务回滚、目标聊天恢复。

## 改动范围

App（名称/图标视图/三模式选择/文件选择/映射/确认/记录）、Core（模式/路径/三操作引擎）、CSupport（原子交换/排他移动）、ContainerAccess（安装元信息/图标适配）、资源图标、版本与打包脚本、Tests/UITests、当前Docs和README。未改其他工程/原始SDK/全局Xcode/原BundleID/最低系统/entitlement。
